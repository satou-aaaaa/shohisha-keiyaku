# 消費者契約のきまり（shohisha-keiyaku）

うそを言われた？帰らせてくれない？「一切責任を負いません」という条項は？お店や会社と結んだ契約の場面を見て、消費者契約法の決まりどおりの答え（取り消せるか・その条項は無効か・いつまでか）を選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/shohisha-keiyaku/>

- 答えは、e-Gov 法令検索の消費者契約法（<https://laws.e-gov.go.jp/law/412AC0000000061>）の条文（第2条・第4〜10条。2026年11月17日に読んだ、2026年6月24日の版）で確かめたことだけです。
- 人の名前・店の名前・金額は作り話です。判例・クーリング・オフ（特定商取引法）・適格消費者団体の差止め・金額のこまかい計算は、このゲームでは答えにしません。一人ずつの事情の判断も答えにしません。
- このゲームは消費者契約法のきほんを知る練習です。法律の助言ではありません。公式の情報の代わりではありません。自分の場合どうなるかは、消費者ホットライン188（いやや）や専門家に確かめてください。 消費者ホットライン: <https://www.caa.go.jp/policies/policy/local_cooperation/local_consumer_administration/hotline/>
